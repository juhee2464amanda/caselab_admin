## daily — 시작 순서

- 작업 시작 시 1순위 확인: **씨앗 수집 현황** (Hermes 봇들이 밤새 쌓은 것), 그다음 텔레그램 콘텐츠
- 현재 단계는 팔로워·콘텐츠 축적 전 — 지표 리포트보다 **씨앗의 품질**이 우선이다

## content-worth — 콘텐츠화 가치 판정 (3문 필터)

씨앗을 콘텐츠로 전환하기 전, 아래 3문에 **전부** 답해야 한다. 하나라도 비면 draft로 올리지 않는다:

1. **아픔**: 타겟(한국 실무자·사이드프로젝트러)의 어떤 고민을 *지금* 겪고 있는가 — 한 문장으로 쓸 것
2. **타이밍**: 왜 이번 주여야 하는가 (출시·변경·이슈) — 근거 링크 1개 첨부
3. **적용**: 읽은 사람이 자기 일에 바로 쓸 수 있는 형태인가 (복붙 프롬프트·단계·설정값 중 하나 이상 포함)

- 3문을 통과해도 판단이 **애매하면 기본값은 폐기**. 일정을 지키려고 발행하지 않는다.
- 봇·세션이 이 필터를 돌릴 때는 3문의 답을 draft 메모에 남겨서 검수자가 재검증할 수 있게 한다.

## quality — 좋음과 위대함의 차이

- great = **실측·검증된 사실** + **바로 따라할 수 있음**. 이 둘이 없으면 good에서 멈춘 것이다.
- 숫자·가격·기능 주장은 확인된 것만 쓴다 (발행 전 가격 재검증 게이트와 연동)
- 실행 불가능한 추상론은 콘텐츠가 아니다 — 복붙 가능한 구체물이 반드시 들어간다
- 금지 문구: "직접 써본 것만" "검증한" 류의 사실 아닌 채널 주장 (invariants 참조)

## escalation — 창업자 전결 (예외 없음)

- **최종 발행**: amanda만 누른다. 봇·세션·스킬은 draft까지가 권한의 끝
- **가격·유료 전환**: is_paid, pricing_tier, 유료 ebook 전환 — amanda 전결

## exceptions — 표준 프로세스를 벗어나는 조건 (이 3가지뿐)

1. **시의성 속보**: 큰 AI 뉴스가 터지면 검수 큐 순서를 건너뛰고 우선 처리 — 단 content-worth 3문과 발행 게이트는 그대로 유지
2. **품질 미달**: 애매하면 발행하지 않고 폐기 — 일정보다 품질
3. **비용 급증**: API·인프라 비용이 튀면 자동화를 멈추고 원인부터 찾는다

## autonomy — 자율성 다이얼 (결정 단위 · 설정 레벨을 넘는 것은 출고 금지)

L1 조회 → L2 초안(승인 필요) → L3 실행+예외 플래그 → L4 독립 실행 → L5 자가 감사

| 업무 | 현재 | 다음 목표 |
|---|---|---|
| 씨앗 수집 (Hermes 봇 6) | L4 독립 실행 | L5 (수집 품질 자가 검사 추가) |
| 초안 적재 (push-asset) | L3 (draft 자동, 발행은 사람) | 유지 |
| 콘텐츠 가치 판정 (3문 필터) | L1~L2 (필터 답안 초안까지) | L3 (통과분 자동 draft) |
| 카드뉴스·썸네일 생성 | L2 (초안 생성, 픽셀 검수 필수) | L3 |
| 발행 | **L1 고정** | 고정 (전결) |
| 가격·유료 전환 | **전결** | 고정 |
