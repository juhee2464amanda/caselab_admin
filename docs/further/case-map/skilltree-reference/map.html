SKILLTREE

The map of every AI job-to-be-done in a business.
7 departments · 34 functions · 137 jobs · ~296 skills.
THE DOCTRINE

Every AI department starts at the same node. The Knowledge Base at the centre of the wheel is node zero · every department reads from it and writes back to it. No knowledge base, no autonomy. From there, each branch has a sequence: jobs closer to the root unlock the jobs further out. This is not an org chart. It is a deployment order.

HOW TO USE IT
  1. Explore. Click a department on the wheel to enter its tree. Every node is a job AI can hold today, with the skills that make it run.
  2. Assess. Open any job and mark where you are · not started, in development, or live. Your tree is saved in this browser. The progress bar is yours.
  3. Build in order. Start at the node marked START HERE in each department, then follow the branch outward. Jobs list what they build on · respect the sequence and each build makes the next one easier.

READING THE MAP

Filled nodes are jobs that can run fully autonomous today. Outlined nodes run human-assisted. Dim nodes are still human-led · mapped so you can see what's coming. A colored ring is your own mark: that job is live in your stack.

Nothing on this map removes the human. Every job states who stays in the loop and what they own · autonomy changes the human's job from doing to directing, and the businesses that get this right deploy faster, not slower.
